# Contributing to prompt-craftsman

Thank you for your interest in contributing to **prompt-craftsman**! This guide outlines how you can help improve the project.

## Code of Conduct

By participating in this project, you agree to keep interactions respectful and constructive. Harassment of any kind will not be tolerated.

## How to Contribute

### Reporting Issues

1. Search existing issues first to avoid duplicates.
2. When opening a new issue, include:
   - A clear and descriptive title
   - Steps to reproduce (if applicable)
   - Expected behavior vs. actual behavior
   - Your environment (OS, app/TRAE version, etc.)

### Suggesting Features

1. Check that the feature hasn't already been requested.
2. Open an issue describing:
   - What you want to achieve
   - Why it's needed (use case)
   - How you'd expect it to work

### Submitting Code Changes

1. Fork the repository and create a feature branch:
   ```bash
   git checkout -b feat/your-feature-name
   ```
2. Make your changes. This project is a pure Markdown skill package — no build step or dependencies are required.
3. Verify the `SKILL.md` structure and formatting are consistent with the existing content.
4. Commit your changes with a clear message.
5. Push your branch and open a Pull Request.

## Guidelines

- Keep the `SKILL.md` file in the repository root (required for `skills.sh` discovery).
- Follow the existing Markdown style: consistent heading levels and formatting.
- Keep content clear and concise. Avoid unnecessary verbosity.
- Ensure `README.md` and `README.zh-CN.md` stay in sync when you change project documentation.

## Commit Message Style

Prefer conventional commit prefixes:

- `feat:` for new features
- `fix:` for bug fixes
- `docs:` for documentation changes
- `refactor:` for code refactoring
- `chore:` for maintenance tasks

## Questions?

If you need help, open an issue and the maintainers will get back to you.

Thank you for contributing!
