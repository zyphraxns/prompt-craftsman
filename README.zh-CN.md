# Prompt Craftsman

通过结构化访谈，为任意 LLM 生成和优化高质量的提示词。

[English](README.md) | **简体中文**

大多数提示词请求都以一句模糊的话开始——比如"帮我写一个整理课堂笔记的提示词"——而多数提示词工具会当场产出一个千篇一律的通用提示词。Prompt Craftsman 的做法相反：它先进行一段简短的结构化访谈（每轮几个问题，每个问题附推荐答案），再写出真正贴合任务的提示词。

## 功能特性

- **一个技能、两种模式**
  - **生成（Generate）** —— 访谈 → 从零写出新提示词。
  - **优化（Optimize）** —— 诊断现有提示词的弱点 → 确认 → 重写。
- **结构化模块体系** —— 角色、背景、任务、输入、约束、输出格式、质量标准、示例。按需裁剪，不总是全量包含。
- **三档长度可选** —— 简洁（一段话）、标准（分节）、详细（全模块 + 示例 + 质量标准）。写前与用户确认。
- **每个问题都附推荐答案** —— 用户有快速默认项，同时保留自主选择权。
- **分轮提问** —— 每轮最多 3-4 个问题，按依赖顺序推进，完整性清单（任务 + 输出格式必填）覆盖即停止。
- **合理的兜底** —— 用户拒绝回答时，明确列出假设、交付一版标准档草稿，并用 `PENDING: ...` 标注待确认项。
- **提示词语言可控** —— 默认跟随对话语言，也可显式设为英文。

## 安装

将 `prompt-craftsman` 文件夹复制到你的 agent 技能目录，例如：

```bash
# Claude Code
cp -r prompt-craftsman ~/.claude/skills/

# TRAE
cp -r prompt-craftsman ~/.trae-cn/skills/
```

或者保留在仓库中，直接引用文件夹路径。

## 使用方法

可以这样说：

- "帮我写一个整理课堂笔记的提示词" —— 生成模式，访谈开始。
- "帮我把这个提示词改好：`你是一个助手，帮我写周报`" —— 优化模式，先诊断。
- "帮我写一个把会议记录变成行动项的提示词。"
- "I need a detailed English prompt for competitive analysis."（我需要一个详细的英文竞品分析提示词。）

技能会先分几轮提问（每轮附推荐答案），确认长度档位与提示词语言，然后交付：

```
<提示词，置于围栏代码块中>

**为什么这样设计（Why it's built this way）**
- ...
```

## 工作原理

1. **访谈** —— 每轮 3-4 个按依赖排序的问题，每个附推荐项；完整性清单覆盖后停止。
2. **确认** —— 长度档位（简洁 / 标准 / 详细）与提示词语言。
3. **撰写** —— 按结构化模块组装提示词，按需裁剪。
4. **交付** —— 提示词 + 关键设计选择的简短说明。
5. **迭代** —— 提供一次轻量的试跑 / 修订入口。
